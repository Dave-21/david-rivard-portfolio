# David Rivard - Portfolio

Personal portfolio website for David Rivard, Software Engineer. Built with Next.js App Router, Tailwind CSS, and MDX.

## Features

- Responsive layout with Light and Dark mode
- Detailed system architecture pages rendered with MDX
- Fast performance and SEO optimization

## Development

Start the local dev server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```
