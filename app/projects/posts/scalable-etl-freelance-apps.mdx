## Overview

Between 2019 and 2022, I worked as an independent software developer delivering dozens of client projects from initial concept through production deployment (0 to 1). Work was delivered for clients across diverse industries and business sizes, spanning full-stack web platforms, cross-platform mobile applications, Windows desktop software, large-scale data engineering pipelines, live sensor integrations, and legacy application overhauls.

---

## 0-to-1 Full-Stack, Desktop & Mobile Software

* **Web applications & portals**: Built custom web solutions using React, TypeScript, Node.js, PHP, and Python (Django, Flask), delivering business tools for inventory tracking, customer orders, and staff scheduling.
* **Windows & desktop software**: Engineered high-performance desktop utilities in C# and .NET using WPF, WinUI 3, WinForms, Blazor, and Razor for clients needing fast, offline workstation tools.
* **Cross-platform mobile**: Developed cross-platform applications using .NET MAUI and modern web wrappers tailored to client field operations.

---

## High-Volume Data Pipelines & Visualization

* **Large-scale ETL processing**: Built automated Python and PySpark data pipelines to ingest, clean, and normalize massive datasets from multi-format spreadsheets (CSV, Excel), APIs, and relational databases.
* **Interactive visual analytics**: Built visualization dashboards that helped non-technical business stakeholders explore large datasets, identify trend patterns, and automate weekly reporting workflows.
* **Database architecture & optimization**: Designed normalized relational database schemas in PostgreSQL, MySQL, Microsoft SQL Server, and SQLite, adding targeted B-tree indexing to keep search queries fast.

---

## Legacy Modernization & Codebase Overhauls

* **Bug fixing & performance tuning**: Diagnosed and resolved memory leaks, race conditions, and query bottlenecks in existing client codebases.
* **Full system overhauls**: Re-architected outdated legacy applications, migrating older desktop and web codebases to modern stacks while preserving historical data and existing business logic.

---

## Automation, Hardware Sensors & Machine Learning

* **Live sensor integration**: Built data acquisition tools that ingested and parsed real-time telemetry from physical hardware sensors and serial devices.
* **Computer vision & OCR**: Developed automated document processing workflows using OpenCV and Tesseract OCR to eliminate manual data entry.
* **Voice & audio workflows**: Integrated speech-to-text and text-to-speech pipelines into business utilities for hands-free and voice-enabled interactions.
