## Overview

From 2019 to 2022, as a Freelance Software Developer, I worked directly with diverse clients to scope, design, and deliver end to end custom software solutions, high throughput ETL data pipelines, and responsive web and desktop applications.

---

## Technical Highlights

### 1. Data Intensive Web and Desktop Applications
* Architected robust backend APIs and data processing systems in Python (Django and Flask) and C# (.NET with WPF and WinUI 3).
* Designed dynamic web frontends in ReactJS, incorporating interactive data visualizations and real time state management.

### 2. ETL Pipelines and Database Optimization
* Developed scalable ETL pipelines for aggregating, filtering, and transforming massive multi format datasets.
* Optimized relational database schemas (MySQL, PostgreSQL, MS SQL Server) with indexing and query tuning to support high concurrency workloads.

### 3. Client Collaboration and Quality
* Managed full lifecycle development: requirements gathering, architecture design, automated unit testing, deployment, and documentation.
* Built reusable software libraries and UI component suites to maintain code quality and fast delivery timelines.
