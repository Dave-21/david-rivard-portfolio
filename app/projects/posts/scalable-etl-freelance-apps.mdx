## Overview

Between 2019 and 2022, I worked as a freelance software developer building custom web applications, desktop software, and data pipelines for small businesses. Most clients reached out because commercial off-the-shelf software was too expensive or lacked the specific workflows they needed.

Working directly with business owners meant handling the entire project: scoping requirements, designing database schemas, writing frontend and backend code, and deploying the software.

---

## What I Delivered

* **Web applications**: Built responsive web tools in React with Python backends (Django and Flask) for tracking customer orders, warehouse inventory, and staff schedules.
* **Desktop utilities**: Developed native Windows desktop software in C# (.NET) using WPF and WinUI 3 for clients who needed fast offline performance on local PCs.
* **Automated ETL scripts**: Wrote Python scripts with pandas and OpenPyXL to automatically ingest, clean, and convert messy multi-format spreadsheets into organized SQL tables.
* **Database design**: Designed and optimized relational databases in PostgreSQL, MySQL, and SQL Server, adding indexes so searches and reports run quickly.
* **Automated reporting**: Built automated scripts to generate recurring business reports and run daily database backups, saving staff hours of manual work each week.
* **Client collaboration**: Met directly with business owners to set milestones, wrote unit tests for stability, and provided user guides so staff could run the software independently.
