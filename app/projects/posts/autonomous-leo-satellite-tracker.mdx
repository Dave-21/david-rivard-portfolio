## Overview

As Lead Software Engineer on university research at Lake Superior State University (Aug 2024, May 2025), I led an engineering team building an autonomous computer vision system designed to detect, identify, and continuously track Low Earth Orbit (LEO) satellites in real time using small aperture optical arrays.

---

## Technical Innovations and Architecture

### 1. High Speed Computer Vision & Telemetry Engine (120 FPS)
* Developed high-speed image processing pipelines capable of isolating fast-moving, low-brightness point targets against astronomical star fields at **120 images per second (120 FPS)**.
* Created frame-by-frame image processing algorithms, feature extraction matrices, and trajectory prediction sequences to perform confident visual entity matching.
* Combined frame differencing, dynamic background subtraction, and object detection models (YOLO and OpenCV) to classify optical satellite signatures in high-noise environments.

### 2. Orbital Trajectory Prediction & Autonomous Control
* Implemented real-time orbital trajectory algorithms using Two Line Element (TLE) sets and SGP4 propagation models.
* Calculated target azimuth and elevation angles to drive automated motor mounts, ensuring continuous closed-loop camera tracking across pass windows.
* Low-latency motor control loops built in C++ and Python delivered autonomous target acquisition without manual operator intervention.

### 3. Full-Stack Web Dashboards & Telemetry Analytics (200 GB/Day)
* Built secure full-stack web dashboards using React and ASP.NET MVC server-side APIs for live system observability, serving **300 active users** and processing up to **200 GB of telemetry data daily**.
* Built real-time analytics pipelines to record tracking metrics, flag structural verification anomalies, and monitor system health.
