## Overview

As Software Engineer for a Contract Project with Chippewa County Information Systems (Jan 2024, May 2024), I led the complete modernization and re platforming of an obsolete Microsoft Access county inventory tracking tool into a scalable, high throughput web application.

The new system streamlined asset management across all county municipal departments, establishing zero downtime data integrity during legacy migration.

---

## Technical Achievements and Architecture

### 1. Legacy Migration and Zero Downtime Transition
* Engineered secure data conversion scripts to parse and migrate thousands of legacy records from Microsoft Access to MariaDB and MySQL with zero operational downtime.
* Enforced database normalization, foreign key constraints, and transactional consistency to guarantee data integrity across county departments.

### 2. High Throughput RESTful APIs
* Architected RESTful backend services in PHP to handle high frequency asset tracking, check-ins, check-outs, and document management.
* Improved overall system wide asset processing speeds by over 70%, drastically cutting administrative wait times.

### 3. Custom Reporting and User Management
* Implemented responsive input forms with client side validation and customizable reporting features, generating instant actionable insights for county administrators.
* Reduced critical reporting errors and data entry bugs by nearly 45%.
* Built automated backup and export tooling supporting multiple formats (CSV, PDF, JSON).
