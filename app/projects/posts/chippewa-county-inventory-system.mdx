## The Problem

County staff were tracking physical equipment, property, and official documents using a shared desktop Microsoft Access database.

Because Access was not built for multiple people to use at once, staff had frequent problems:

* Files would lock up when two people opened them at the same time.
* Searches and record lookups were slow.
* The file was at risk of getting corrupted during edits.

As a Software Engineer on contract for Chippewa County Information Systems (Jan 2024 - May 2024), I was hired to replace the desktop file with a secure, centralized web application accessible from standard web browsers on the county network.

---

## What I Built

* **Database migration**: Designed a clean relational schema in MySQL and MariaDB, wrote migration scripts in PHP and SQL, and migrated all historical records with zero data loss.
* **Fast web interface**: Built a clean interface in vanilla JavaScript using Fetch and AJAX so staff could search, filter, and edit records instantly without full page reloads.
* **Secure backend APIs**: Wrote modular PHP REST endpoints using PDO prepared statements to handle lookups, edits, and file uploads securely.
* **Custom admin dashboard**: Built dedicated in-app admin pages for adding users, managing roles, and setting department permissions without exposing raw database tools.
* **Audit log viewer**: Added an audit history page with timestamps and user names so administrators can see who modified any record.
* **Export tools**: Built one-click report tools so staff can export filtered data to CSV, JSON, or formatted PDF files for county audits.
* **Server setup**: Deployed the app on a dedicated Linux virtual machine with automated daily backup cron jobs and strict file permissions.

## Technologies Used

* **Backend & APIs**: PHP, RESTful APIs, PDO (Prepared Statements), Apache 2.4, mod_rewrite, Session Management
* **Database Architecture**: MySQL, MariaDB, 3NF Normalization, B-Tree Indexing, Composite Indexing, Foreign Keys, ACID Transactions
* **Frontend Development**: Vanilla JavaScript (ES6+ Fetch / AJAX), HTML5, CSS3, Responsive UI
* **Security & Administration**: Role-Based Access Control (RBAC), Custom Admin Dashboards, User Management, Bcrypt Password Hashing, Audit Logging
* **Infrastructure & Tooling**: Linux Virtual Machine, Bash Automation, Cron Scheduling, Automated Backups, Git
