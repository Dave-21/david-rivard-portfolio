## Overview

As Software Engineer for a contract project with Chippewa County Information Systems (Jan 2024, May 2024), led the architectural design, legacy migration, full stack development, and deployment of a modern asset and document management web platform. The project replaced an unnormalized, single file Microsoft Access system prone to concurrency locks and file corruption with a centralized, high concurrency LAMP web application.

Delivered a production ready, hardened Linux virtual machine appliance complete with custom administrative tooling, automated backup rotation, schema validation pipelines, and comprehensive technical documentation.

---

## Technical Architecture & Key Deliverables

### 1. Zero Downtime Legacy Database Migration & Schema Normalization
* **ETL Pipeline & Schema Design:** Engineered automated PHP and SQL extraction and transformation scripts to migrate thousands of legacy records from Microsoft Access to a normalized MariaDB and MySQL relational schema.
* **Referential Integrity:** Structured relational entities enforced with foreign keys, strict cascade constraints, and transactional ACID boundaries.
* **Data Parity & Audit Verification:** Implemented automated pre and post migration validation scripts utilizing row count reconciliation, cryptographic checksum hashing, and orphan record audits to guarantee zero data loss during cutover.

### 2. RESTful API Architecture & Asynchronous Interface
* **Modular REST Endpoints:** Designed backend PHP API routes handling standard HTTP verbs (GET, POST, PUT, DELETE) with structured JSON request and response payloads and explicit HTTP status codes.
* **Web Server Routing:** Configured Apache mod_rewrite to direct dynamic resource paths through a centralized PHP routing controller while maintaining direct access for static assets.
* **Client Side Asynchronous UI:** Built responsive frontend workflows in vanilla JavaScript utilizing Fetch and AJAX to execute non-blocking CRUD operations, live asset transfers, and dynamic DOM updates without full page reloads.

### 3. Query Optimization & Indexing Strategy
* **Point Lookup Acceleration:** Created unique B-Tree indexes on primary search identifiers and record keys, transforming asset scans into O(log N) point lookups and eliminating table scans.
* **Composite Filtering:** Added composite indexes to accelerate high frequency multi parameter filtering across county departments.
* **Covering Index Optimization:** Implemented covering indexes on historical audit logs, enabling instant report generation without secondary memory filesorts and improving overall system processing speeds by **>70%**.

### 4. Input Validation, Dynamic Reporting & Export Engine
* **Dual Layer Validation:** Enforced client side regex and type constraints in JavaScript paired with server side validation and PHP PDO prepared statements, reducing reporting errors and invalid entries by **45%**.
* **Dynamic Query & Reporting Tool:** Built an administrative interface allowing custom filtering by date range, department, status, and asset category.
* **Multi Format Export Pipeline:** Developed stream based export utilities generating downloadable **CSV**, structured **JSON**, and formatted **PDF** audit reports for county compliance and fiscal reviews.

### 5. Custom Administrative Dashboard & Security Hardening
* **Dedicated Admin Control Panel:** Engineered native, in application administrative interfaces for user provisioning, role assignments, on demand backup triggers, and real-time audit log inspections with user attribution, eliminating the security risks of exposing raw database management tools.
* **Attack Surface Reduction:** Kept database ports isolated behind application level Role-Based Access Control (RBAC), parameterized PDO queries, and Bcrypt password hashing to prevent unauthorized access.
* **Turnkey Virtual Appliance:** Packaged and hardened a complete Linux, Apache, MariaDB, PHP (LAMP) virtual machine image configured with automated cron differential backups, log rotation, and step by step deployment documentation.
